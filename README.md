# Amigo Secreto
Una aplicación web simple que te permite agregar nombres a una lista y luego seleccionar uno al azar. Perfecta para sorteos, selección de turnos o cualquier situación donde necesites elegir un nombre de forma aleatoria.

## 🚀 Características
Interfaz intuitiva: Diseño limpio y fácil de usar

Agregar nombres: Añade nombres individuales a la lista

Visualización en tiempo real: Los nombres se muestran inmediatamente después de agregarlos

Selección aleatoria: Elige un nombre al azar de la lista con un solo clic

## 🛠️ Tecnologías Utilizadas
HTML5

CSS3

JavaScript

## 📦 Instalación
Clona o descarga este repositorio

Abre el archivo index.html en tu navegador web

¡Listo! Puedes comenzar a usar la aplicación
